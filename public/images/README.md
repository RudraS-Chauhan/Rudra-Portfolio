# Image Assets Directory Structure

Organized subfolders for portfolio assets:

- `/public/images/projects/` — Screenshots for AtlasCV, EventFit AI, ECHO-GATE Robotics (`atlascv-main.png`, `eventfit-main.png`, `echogate-main.png`, etc.)
- `/public/images/tech/` — Custom logos and tech icons for framework tools
- `/public/images/profile/` — Headshots and profile avatars
- `/public/images/certifications/` — Certificates and achievement badges
